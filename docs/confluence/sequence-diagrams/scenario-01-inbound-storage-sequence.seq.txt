#1 입고 및 보관
부품 입고 요청부터 창고 보관, 데이터베이스 갱신과 작업 로그 기록까지

Participants: 관리자, 관제 화면, 중앙 관리 서버, 운반 로봇, AI 서버, 데이터베이스

1. 관리자 -> 관제 화면: 입고 요청
2. 관제 화면 -> 중앙 관리 서버: 작업 등록
3. 중앙 관리 서버 -> 중앙 관리 서버: 로봇 선택
4. 중앙 관리 서버 -> 운반 로봇: 입고 구역 이동
5. 운반 로봇 -> AI 서버: 수령 확인
6. AI 서버 -> 운반 로봇: 리프트 확인
7. 운반 로봇 -> 운반 로봇: 창고 구역 이동
8. 운반 로봇 -> 운반 로봇: 지정 위치 하역
9. 운반 로봇 -> 중앙 관리 서버: 작업 완료
10. 중앙 관리 서버 -> 데이터베이스: 재고/이력 갱신
11. 중앙 관리 서버 -> 데이터베이스: 작업 로그 기록
12. 중앙 관리 서버 -> 관제 화면: 완료 상태 전달
13. 관제 화면 -> 관리자: 완료 표시
14. 중앙 관리 서버 -> 운반 로봇: 대기/충전 장소 이동

Notes:
- 장애물 발생 시 #3
- 적재 실패 시 관리자 확인
- 위치 불가 시 대체 위치 확인
