#2 출고
창고 부품을 찾아 출고 구역으로 운반하고 작업 로그를 기록

Participants: 관리자, 관제 화면, 중앙 관리 서버, 데이터베이스, 운반 로봇, AI 서버

1. 관리자 -> 관제 화면: 출고 요청
2. 관제 화면 -> 중앙 관리 서버: 작업 등록
3. 중앙 관리 서버 -> 데이터베이스: 재고/위치 확인
4. 데이터베이스 -> 중앙 관리 서버: 확인 결과
5. 중앙 관리 서버 -> 중앙 관리 서버: 로봇 선택
6. 중앙 관리 서버 -> 운반 로봇: 창고 구역 이동
7. 운반 로봇 -> AI 서버: 수령 확인
8. AI 서버 -> 운반 로봇: 확인 완료
9. 운반 로봇 -> 운반 로봇: 출고 구역 이동
10. 운반 로봇 -> 운반 로봇: 출고 구역 하역
11. 운반 로봇 -> 중앙 관리 서버: 작업 완료
12. 중앙 관리 서버 -> 데이터베이스: 재고/이력 갱신
13. 중앙 관리 서버 -> 데이터베이스: 작업 로그 기록
14. 중앙 관리 서버 -> 관제 화면: 완료 상태 전달
15. 관제 화면 -> 관리자: 출고 완료 표시
16. 중앙 관리 서버 -> 운반 로봇: 대기/충전 장소 이동

Notes:
- 재고 부족 시 작업 불가 알림
- 같은 구역 사용 중이면 대기
