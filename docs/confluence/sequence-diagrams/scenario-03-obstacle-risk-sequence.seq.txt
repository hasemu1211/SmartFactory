#3 장애물 및 위험 상황 대응
장애물 감지 후 즉시 정지, 정적 장애물 우회, 동적 장애물 확인, 로그 기록

Participants: 운반 로봇, AI 서버, 장애물, 중앙 관리 서버, 데이터베이스, 관제 화면, 관리자, 장애물 해소

1. 운반 로봇 -> 운반 로봇: 이동 중
2. 장애물 -> AI 서버: 나타남
3. AI 서버 -> 운반 로봇: 장애물 감지
4. 운반 로봇 -> 운반 로봇: 즉시 정지
5. 운반 로봇 -> 운반 로봇: 정적 장애물
우회 기동
6. AI 서버 -> 중앙 관리 서버: 동적 장애물 확인
7. 중앙 관리 서버 -> 관제 화면: 위험 알림
8. 관제 화면 -> 관리자: 확인 요청
9. 장애물 해소 -> AI 서버: 해소
10. 중앙 관리 서버 -> 중앙 관리 서버: 상황 처리/판단
11. AI 서버 -> 중앙 관리 서버: 해소 인지
12. 중앙 관리 서버 -> 운반 로봇: 재개/대기 지시
13. 중앙 관리 서버 -> 데이터베이스: 위험 처리 로그 기록

Notes:
- 미등록 사람은 경고
- 로봇끼리는 순서 지정
- 낙하/통신 끊김/긴급 정지는 중지
