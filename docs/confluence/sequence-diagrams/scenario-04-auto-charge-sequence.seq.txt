#4 충전 대기
배터리 부족 시 충전 구역으로 이동해 충전 대기 상태를 표시

Participants: 중앙 관리 서버, 운반 로봇, 충전 구역, 데이터베이스, 관제 화면, 관리자

1. 중앙 관리 서버 -> 운반 로봇: 배터리 확인
2. 운반 로봇 -> 중앙 관리 서버: 상태 전달
3. 중앙 관리 서버 -> 중앙 관리 서버: 20% 미만 제외
4. 중앙 관리 서버 -> 운반 로봇: 충전 이동 지시
5. 운반 로봇 -> 충전 구역: 충전 구역 이동
6. 충전 구역 -> 운반 로봇: 충전 시작
7. 운반 로봇 -> 관제 화면: 충전 중 표시
8. 운반 로봇 -> 중앙 관리 서버: 50% 이상 알림
9. 중앙 관리 서버 -> 운반 로봇: 작업 가능 복귀
10. 중앙 관리 서버 -> 데이터베이스: 충전/복귀 로그 기록
11. 중앙 관리 서버 -> 관제 화면: 작업 가능 상태 전달
12. 관제 화면 -> 관리자: 상태 표시

Notes:
- 이동 불가 시 관리자 확인
- 진행 중 작업이 없을 때 충전
