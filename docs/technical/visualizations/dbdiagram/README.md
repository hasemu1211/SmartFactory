# SmartFactory DB Diagram

현재 기준 DB 자료는 `final/` 폴더만 사용한다.

- `final/smartfactory-db-final.dbml`: 최종 DBML 원본
- `final/smartfactory-db-final-overview.drawio`: Confluence draw.io 확장앱에 삽입한 편집 가능한 원본
- `final/smartfactory-db-final-overview.png`: 문서/리뷰용 미리보기 이미지
- `final/smartfactory-db-final-overview.drawio.png`: draw.io XML이 포함된 편집 가능한 PNG export
- `final/smartfactory-db-final-overview.svg`: SVG export

과거 MVP/시나리오/분할 DBML 초안은 혼동 방지를 위해 제거했다.
